# DaoAtto

DaoAtto Core enables real-time data processing and management through auto-scaling and load balancing capabilities within the DaoAtto Engine.

The key benefits of using DaoAtto include:

- DaoAtto Core enables real-time data
- processing and management through auto-scaling
- and load balancing capabilities within

## Installation

1. Clone the repository: `git clone https://github.com/Anabelengil/DaoAtto.git`
2. `cd DaoAtto`
3. Install in editable mode: `pip install -e .`

## Configuration

Most behavior is controlled via command-line flags:
- `--verbose`: enable detailed logging
- `--config <path>`: point to a custom config file
- `--dry-run`: preview changes without applying them
